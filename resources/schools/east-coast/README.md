# School: east-coast

- **Characters** speak English with the slang of the sources.
- **Lyrics** are a romanticised layer: a claim backed only by lyrics is flagged as such. Short quotes with a link may be public; long ones go to `data/` (agreement 11 in `docs/PLAN.md`).
- **Debrief** in Ukrainian (agreement 9).
